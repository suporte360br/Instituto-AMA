# Instituto-AMA

Site do **Instituto AMA** — Amor, Misericórdia e Ação — https://institutoama.social.br

Site estático (HTML + CSS + JS), hospedado no GitHub Pages a partir da branch `main`.

## Como editar

- Páginas: `index.html`, `sobre-nos/`, `blog/`, `referencias/`, `contato/`, `privacidade.html`
- Novo artigo no blog: copie `blog/constelacao-familiar.html`, troque o texto e adicione um cartão em `blog/index.html`
- Cores e layout: `assets/css/style.css` (cores no topo, em `:root`)
- Imagens: `assets/img/`
- E-mail que recebe o formulário de contato: `assets/js/main.js` (`EMAIL_DESTINO`)

Qualquer alteração enviada para a branch `main` é publicada automaticamente em 1–2 minutos.
